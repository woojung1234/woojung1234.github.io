## 📋 프로젝트 개요

**개인의 소득과 가계 상황을 분석하여 맞춤형 복지서비스를 추천하고, 통합 가계부 기능을 제공하는 모바일 애플리케이션**

### 🎯 해결하고자 한 문제
- 복잡한 복지제도로 인한 정보 접근성 부족
- 개인 상황에 맞는 복지 혜택 발견의 어려움
- 가계 관리와 복지 활용의 분리된 접근

### 🚀 핵심 기능
1. **맞춤형 복지서비스 추천**: 소득, 가족구성, 거주지역 기반 개인화 추천
2. **통합 가계부**: 수입/지출 관리와 복지 혜택 연동
3. **복지 신청 알림**: 신청 기간과 조건 자동 모니터링
4. **절약 효과 분석**: 복지 활용을 통한 가계 개선 효과 시각화

### 🛠 기술 스택
- **Frontend**: React Native, Expo
- **Backend**: Node.js, Express
- **Database**: Firebase Firestore
- **API**: 정부 복지서비스 API, 금융 API
- **인증**: Firebase Authentication

### 📊 주요 성과
- **사용자 발견율**: 평균 3.2개의 새로운 복지혜택 발견
- **절약 효과**: 월평균 15만원 가계비 절감 달성
- **사용자 만족도**: 앱스토어 4.6/5.0 평점

### 🔍 기술적 도전과 해결
**문제**: 복잡한 복지 자격 조건의 로직 구현
**해결**: 규칙 기반 엔진과 의사결정 트리 알고리즘 활용

**문제**: 실시간 정부 데이터 동기화
**해결**: 웹크롤링과 API 조합으로 데이터 신뢰성 확보

### 💡 사회적 임팩트
- **복지 사각지대 해소**: 정보 부족으로 놓치는 혜택 최소화
- **디지털 포용성**: 복지 정보의 접근성 개선
- **개인 재정 건전성**: 체계적인 가계 관리 지원

### 🏆 특별한 의미
이 프로젝트는 **기술을 통한 사회 문제 해결**의 대표 사례입니다. 단순한 앱 개발을 넘어서 실제 사용자의 경제적 부담을 덜어주는 실용적 가치를 창출했습니다.
