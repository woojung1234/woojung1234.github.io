## 📋 프로젝트 개요

**개인의 선호도와 여행 조건을 분석하여 최적의 여행지를 추천하는 AI 기반 서비스**

### 🎯 해결하고자 한 문제
- 수많은 여행 정보 속에서 개인에게 맞는 여행지 선택의 어려움
- 개인 취향, 예산, 일정을 종합적으로 고려한 맞춤형 추천의 부재
- 여행 계획 수립 과정의 복잡성과 시간 소모

### 🚀 핵심 기능
1. **개인 맞춤형 추천**: 사용자의 선호도, 예산, 여행 스타일 분석
2. **실시간 정보 연동**: 날씨, 이벤트, 교통 정보 통합
3. **여행 일정 자동 생성**: AI가 최적의 여행 루트와 일정 제안
4. **비용 최적화**: 예산 범위 내에서 최대 만족도 달성

### 🛠 기술 스택
- **Frontend**: React, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express
- **AI/ML**: OpenAI GPT API, Langchain
- **Database**: MongoDB
- **API**: 날씨 API, 지도 API, 항공료 API

### 📊 주요 성과
- **사용자 만족도**: 85% 이상의 추천 정확도 달성
- **처리 속도**: 평균 3초 이내 맞춤형 추천 제공
- **데이터 활용**: 10,000+ 여행지 데이터베이스 구축

### 🔍 기술적 도전과 해결
**문제**: GPT API 응답의 일관성 부족
**해결**: 프롬프트 엔지니어링을 통한 구조화된 응답 형식 확립

**문제**: 실시간 데이터 처리 성능 이슈
**해결**: 캐싱 전략과 비동기 처리로 응답 속도 50% 개선

### 💡 학습 성과
- **프롬프트 엔지니어링** 기법 습득
- **API 통합** 및 데이터 처리 최적화 경험
- **사용자 경험(UX)** 중심의 서비스 설계 역량 향상
